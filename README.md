# Concurrent Java Chat Application

## Overview
Client-server based chat application built in Java. Designed to explore concurrency and thread safety through a multi-threaded environment, and networking concepts. System supports multiple simultaneous clients and group-based messaging.

## Key Features
- Java socket based client-server communication
- Concurrent handling of multiple clients using threads
- Group chat functionality using shared state
- Thread-safe/non-thread-safe implementations
- Unit tests demonstrating thread safety

## Technical Highlights
- Thread management/synchronization
- Race condition handling

## Technologies
Java, Sockets, Threads, JUnit

## Notes
Originally developed as a coursework project at the University of Strathclyde
